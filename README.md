# EXIT AI MVP

Mobile-first Solana token discovery and paper trading. Static site deployed from index.html. Uses DEX Screener public endpoints; samples latest profiles and boosts, not every launch. Requires browser network access and third-party API CORS. No keys or real trades.

Paper trading starts at $100 in browser localStorage, with estimated 0.5% slippage, liquidity-dependent price impact, and $0.01 per trade. These are approximations; not executable prices. Stale quotes are labeled and cannot be sold until refreshed. Browser storage is device-specific and can be cleared.

No AI inference, token authority security checks, holder concentration analysis, or reliable backtesting yet. No investment recommendation is implied.
